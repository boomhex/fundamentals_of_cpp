- Six variants of new:

1: new int, delete int
This is appropriate to use like this:
int *intp = new int();
delete intp;
Because:
When defining a pointer to an integer, you can use new to allocate the memory.
And delete to release the memory.

2: new int[], delete[]
This is appropriate to use like this:
int *intarr = new int[8]();
delete[] intarr;
Because:
When defining a pointer, you can use the brackets to allocate a specified
amount of elements that are consecutive in memory. Using brackets in delete
allows you to free that memory.

3: placement new;
This is appropriate to use like this:
void *mem = new(sizeof(int));
int *intptr = new(mem) int();
intptr->~int();
operator delete(mem);
Because:
This way, you assign memory that was previously unassigned to something else
to your new pointer.

4: operator new
This is appropriate to use like this:
char *chPtr = static_cast<char *>(operator new(3 * sizeof(char)));
operator delete(chPtr);
Because:
This way, you allocate raw memory and assign it to a char pointer. While also
casting it as a character.

5: operator new[]
This is appropriate to use like this:
void *mem = operator new[](3 * sizeof(int));
operator delete[](mem);
Because:
you first obtain raw, uninitialized storage with operator new[]. Since you
didn’t allocate the object with ordinary new, you must call the destructor
explicitly and then free the raw storage with operator delete[].

6: new *[]
This is appropriate to use like this:
string **strs = new string *[argc];
for (size_t idx = 0; idx != argc; ++idx)
    strs[idx] = new string{ argv[idx] };
for (size_t idx = 0; idx != argc; ++idx)
    delete strs[idx];
delete[] strs;
Because:
You obtain an array of ptrs to strings, and you have to delete them one-by-one
before you delete the array of pointers.
